Quero criar dentro do sistema uma tela chamada:

MAPA PATRIMONIAL

Esta tela deve transformar automaticamente os dados do banco em uma representação gráfica visual e interativa do patrimônio empresarial.

O mapa deverá funcionar como uma mistura de:

Organograma
Mapa mental
Diagrama societário
Mapa patrimonial
Fluxograma

O objetivo é permitir visualizar rapidamente:

Qual empresa possui qual ativo.

Quais empresas possuem participação em outras empresas.

Quais imóveis pertencem a cada empresa.

Quais veículos pertencem a cada empresa.

Quais ativos geram receita.

Quais ativos possuem impostos ou dívidas.

Quais bens estão sendo transferidos.

Quais empresas possuem pendências.

==================================================
ESTILO VISUAL
==================================================

Criar interface limpa e moderna.

Fundo:

Branco ou cinza muito claro.

Empresas:

Caixas azul-claro com borda azul.

Imóveis:

Caixas com ícone de prédio ou casa.

Veículos:

Caixas com ícone de veículo.

Receita:

Etiqueta amarela.

Exemplo:

GERA RECEITA

Pendências:

Caixas vermelhas.

Exemplo:

IPTU PENDENTE

DÍVIDA ATIVA

MULTAS

TRANSFERÊNCIAS:

Setas cinza ou azul com indicação:

TRANSFERIR

==================================================
CONEXÕES
==================================================

O mapa deve representar relações através de setas.

Tipos:

Empresa → Empresa

Empresa → Imóvel

Empresa → Veículo

Empresa → Ativo

Ativo → Receita

Ativo → Imposto

Ativo → Dívida

Empresa → Transferência → Empresa

Cada tipo de relacionamento deve possuir cor ou estilo diferente.

==================================================
SALVAR POSIÇÃO
==================================================

O usuário poderá mover elementos manualmente.

Salvar posição de cada caixa no banco.

Assim, quando abrir novamente o mapa, a organização personalizada será preservada.

==================================================
ATUALIZAÇÃO AUTOMÁTICA
==================================================

O mapa deve ser alimentado pelo mesmo banco do sistema administrativo.

Exemplo:

Cadastro de um novo veículo em:

Auto&Co Locação de Veículos LTDA

deve automaticamente criar:

Auto&Co
↓
Veículo

Se esse veículo possuir IPVA vencido:

Auto&Co
↓
Veículo
↓
IPVA pendente

Se o IPVA for pago:

a indicação vermelha deverá desaparecer ou mudar para regularizado.
